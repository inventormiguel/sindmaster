# Conteúdo do repositório

- `public/exemplos/*.svg`: ilustrações desenhadas para este projeto (formas simples em SVG, sem pessoa, marca ou
  lugar real), usadas como "foto de exemplo" do seed. Todas trazem a legenda "Foto de exemplo (ilustração)".
- Regimento interno e convenção do seed (`src/db/seed/dados.ts`): textos escritos para o repositório, marcados
  "Documento fictício para demonstração".
- Nomes de pessoas, empresas e condomínios do seed: fictícios. CNPJs da lista de CNPJs fictícios conferidos
  (dão 404 na BrasilAPI). Telefones vazios. Endereços marcados como fictícios, sem CEP.
