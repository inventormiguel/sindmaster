# Instruções do projeto

A aplicação e sua documentação estão em `software/`. Antes de trabalhar nela, leia `software/AGENTS.md` e `software/contexto.md`. Execute comandos npm e Vercel a partir de `software/`. O repositório Git permanece nesta raiz.

Priorize APIs, MCPs e CLIs autenticadas antes de navegador. Preserve a separação entre os bancos local e de produção; não migre dados locais para produção.
